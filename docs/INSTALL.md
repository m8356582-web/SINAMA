# راهنمای نصب

## پیش‌نیازها

- مرورگر مدرن (Chrome, Firefox)
- حساب Supabase (رایگان)
- حساب GitHub (رایگان)

## مرحله 1: Supabase

1. برو به supabase.com
2. ثبت‌نام کن
3. New Project بزن
4. اسم و رمز بذار
5. صبر کن تا ساخته بشه

## مرحله 2: دیتابیس

1. برو SQL Editor
2. کد SQL رو از docs/DATABASE.md کپی کن
3. Run کن

## مرحله 3: کلیدها

1. برو Settings → API
2. Project URL رو کپی کن
3. anon public key رو کپی کن
4. توی js/config.js بذار

## مرحله 4: گیت‌هاب

1. New Repository بساز
2. اسمش: SINAMA
3. Public باشه
4. فایل‌ها رو آپلود کن

## مرحله 5: فعال‌سازی

1. Settings → Pages
2. Source: main
3. Save
4. 2 دقیقه صبر کن

## مرحله 6: تست

آدرس: https://username.github.io/SINAMA/


## عیب‌یابی

### Supabase وصل نمیشه
- اینترنت رو چک کن
- کلیدها رو دوباره کپی کن

### سایت باز نمیشه
- چند دقیقه صبر کن
- Cache مرورگر رو پاک کن

### کاربر پیدا نمی‌شه
- SQL رو دوباره اجرا کن
- جدول users رو چک کن
